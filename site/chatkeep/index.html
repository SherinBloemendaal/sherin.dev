Chatkeep: your chats move along.

A command-line tool for Cursor and Claude Code. Move or rename a project folder, and its chat history comes along to the new place.

Install

Install Chatkeep

curl -fsSL https://sherin.dev/chatkeep/install.sh | bash
powershell -c "irm https://sherin.dev/chatkeep/install.ps1|iex"
  1. Downloadchatkeep-aarch64-apple-darwin.tar.gz
  2. ChecksumSHA-256 matches SHA256SUMS
  3. Installed~/.chatkeep/bin/chatkeep

macOS and Linux above, Windows below.

What it does

Chats follow the folder.

chatkeep mv rewrites the local references, so the history reattaches at the new path.

One command, both tools.

List, move, copy, split, combine, export and import chats for Cursor and Claude Code alike.

Safe writes.

It refuses while the tool still uses the chats, keeps an undo journal, and -n previews first.

Queue for later.

A command that has to wait goes into a queue that runs once the tool is closed.

Local only.

It never contacts the servers of Cursor or Anthropic.
