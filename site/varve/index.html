What it does

Every engine, fully.

Materialized views, partitions, events, system-versioned tables and Redis streams, each in its own place.

Safe around production.

Environment tags, read-only connections, a plan before every structure change and a confirmation before destructive statements.

Quiet by design.

A dense, calm interface where colour only means something: production is red, and nothing else is.

Secrets stay local.

Passwords and SSH passphrases live in your system keychain; your queries only travel to your own servers.

Fast where it counts.

A Rust core with native drivers, cancellable queries and a grid that stays smooth on large results.
